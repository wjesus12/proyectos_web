# Portafolio de proyectos · Wilmer Jesús Paucar Ayquipa

Portal web profesional con mis proyectos publicados: dashboards de BI, soluciones web para negocio y plataformas de formación.

- Sitio estático (HTML, CSS y JavaScript), sin compilación. Se publica en Netlify desde este repositorio.
- Para agregar o editar un proyecto, modifica el arreglo `PROYECTOS` al final de `index.html` y coloca su captura en `img/`.
